# GitHub synchronization

- Keep this project synchronized with its `origin` GitHub repository.
- After a requested application change is implemented and its relevant tests pass,
  commit the completed source changes to `main` and push them to `origin`.
- Never commit local databases, student records, backups, runtime files, build
  outputs, credentials, or `.env` files.
- Use a concise Turkish commit message describing the completed change.
- If a push fails, report it explicitly instead of claiming GitHub is current.
